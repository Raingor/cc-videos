**规律非常干净**：有具体身份场景的进 600–2200 观看区，抽象情绪的全在 100 观看以下。
**而且涨粉只发生在身份场景里**：送外卖 +7、上学 +3+1，抽象情绪类 0。

原因不难理解——用户点关注不是因为"这只熊好可爱"，而是因为"这个号一直在讲我这种人的事"。

**"贴地气"的可执行定义（三条同时满足）**
1. 有一个能被认领的具体身份（奶茶店店员 / 客服 / 住校生 / 网约车司机）
2. 有可辨认的流程节点（开店→高峰→洗杯子→关店）
3. 每个节点都有一句自嘲，而不是一句鸡汤

### 2.4 便利店这类「普遍但中位低」的职业该怎么做

便利店三个池中位只有 46–51，但方差是全场最高档（139x–164x）——**普通内容淹没，选对切入点就能爆**。看它的头部就知道爆在哪：

| 赞 | 标题 |
|---|---|
| 27000 | 都说夜班是摸鱼天堂，我却在玩命硬扛 |
| 16000 | 便利店扔掉的关东煮不能吃，吃了要罚钱的 |
| 12000 | 当黑梦在便利店做了店员后… |
| 10000 | 晚上11点开始清理废弃食物，这也是最爽时刻 |

**全部靠「内部规则的荒诞」，不是靠「一天流程」。** 外人不知道「报废食品不能吃、吃了要罚钱」，一说出来就有传播力。

所以**低中位 + 高方差的职业，结构要改**：
- 时间轴退为背景，**主线换成一条只有从业者知道的荒诞规则**
- 封面直接把这条规则写出来，而不是写「XX 的一天」
- 适用：便利店、药店（609x）、幼师（283x）、服务员（327x）

反过来，**前台（8.2x）这种低方差池就老实做时间轴**，随手做都有几百赞，不需要找爆点。它的头部标题模式也很统一——`月薪7000+双休 | 朝10晚6 | 行政前台的一天`，**带具体工作条件的数字**。

### 2.5 为什么「普遍职业」值得做（中位数看不到的东西）

中位数只反映「这个词下的内容水平」，反映不了**认领人群规模**。便利店、收银员、前台、早餐店这类的价值在于**双视角共鸣**：
- 从业者：「这就是我」→ 认领、评论、关注
- 顾客：「我见过这个」→ 点赞、分享

本号唯一的涨粉冠军（送外卖 +7 粉）就是典型的双视角职业。所以普遍职业要排，但要按 2.4 挑对切入点。

## 四、栏目规范（每期必须一致）

**栏目名**：`熊也来体验`
来源是本号自己发过的「人 熊也来体验工作的一天」（09-03），把它固化成栏目，比新造词更有延续性。

**标题公式**（两种，二选一）
```
熊也来体验｜<职业>打工的一天        ← 打工线
熊也来体验｜<身份>的一天            ← 校园线
```
必须含「打工」或职业词（进搜索池），必须含栏目名（做系列辨识）。
**不要写成「熊的一天」**（中位 175，比「打工日常」低 3 倍）。

**九宫格 / 视频骨架（两种，按 2.4 选）**

结构 A：**时间轴** —— 低方差池用（前台 8.2x / 客服 24x / 收银员 51x / 奶茶店 72x）
```
封面   ： 栏目名 + 职业 + 一行「↓ 有同行吗」类钩子
02-08  ： 7 个时间节点，每格「时间 + 一句自嘲」
尾图/尾帧： 「熊今天没<出错>，给熊记一功」+ 收藏引导
```

结构 B：**荒诞规则** —— 高方差池用（便利店 164x / 药店 609x / 幼师 283x / 服务员 327x）
```
封面   ： 直接把荒诞规则写出来（如「报废的关东煮不能吃，吃了要罚钱」）
02-04  ： 把这条规则拆开讲清楚，从业者看了会点头
05-08  ： 时间轴退为背景，补其他节点
尾图/尾帧： 同上
```

两种都不得换成抽象情绪——那是本号 44 观看的写法。

**固定动作（每期必做）**
1. 尾图/尾帧固定「给熊记一功」句式，培养系列记忆
2. 置顶评论必须问「**下一期熊去体验什么职业？评论区点单**」——这是本号最缺的评论撬动点（全周仅 15 条评论），而职业点单是天然低门槛
3. 正文出现两次身份词（如"奶茶店""店员"），强化人群标签
4. 每期把上一期的点单结果写进正文，做成"听劝"的闭环

**话题池（每期 7–8 个）**
```
固定：#自嘲熊  #自嘲熊揣手手  #打工人表情包  #精神状态
职业：#<职业名>  #<职业名>日常  #打工日常
校园：#学生党  #住校日常  #早八
```

## 五、发布节奏

**已确认：每周 2 期番外篇**，插进主线排期，不挤掉「熊の文案」和素材位。

| 周内位置 | 内容 | 形式 |
|---|---|---|
| 周一 07:30 | 番外篇 · 视频 | 竖版短视频 12–15s |
| 周三 20:30 | 番外篇 · 图文（同一职业，视频验证过的句子） | 九宫格图文 |
| 周四 17:30 | 素材位 · 表情包 / 贺卡（主线） | 九宫格 |
| 周六 20:30 | 熊の文案（主线） | 九宫格 |

**为什么同一选题要图文 + 视频各做一次**：
两者走**不同的流量池**（视频池曝光 ~8000，图文池 ~1200–3900，见复盘第二节），互不抢量；而且图文有搜索长尾、视频有沉浸播放。同一职业的素材做一次可以出两条内容，边际成本很低。
周一发视频探量 → 周三发图文（间隔 2 天），图文用视频评论区反应最好的那几句。

## 六、制作路线（两条，先看这里再动手）

| | 路线 A：官方贴图合成 | 路线 B：AI 图生视频 |

## 七、这个系列要验证的假设

| 假设 | 看哪个数 | 通过线 |
|---|---|---|
| 身份场景系列能稳定复现 600+ 观看 | 每期观看 | ≥ 600，且 3 期不低于 400 |
| 系列化 + 期数能提升关注转化 | 单期涨粉 | ≥ 5（本号涨粉冠军是 +7） |
| 「职业点单」能撬开评论区 | 单期评论 | ≥ 10（本号全周 15） |
| 标题带「打工」进搜索池 | 观看来源「搜索」占比 | ≥ 5%（本号现 ≤ 0.5%） |
| 同选题图文+视频不互相抢量 | 两条各自曝光 | 后发那条 ≥ 先发那条的 60% |

**止损线**：连续 3 期观看 < 400，停掉该职业线，回到已验证的外卖 / 上学题材做续集。
