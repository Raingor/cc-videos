## 三、出片规范

- 帧尺寸 **1080×1440**，命名 `01.png` … `06.png`
- 熊本体一律官方贴图原图，**不得 AI 生成**。深夜帧可优先翻 `1360541-winter`（色调更沉）
- **明暗曲线不可打乱**：帧 1–2 深蓝、帧 3 暖米、帧 4 暖黄、帧 5 暖橘、帧 6 浅蓝白天
- 道具程序绘制：炉台 = 圆角矩形 + 两个小圆；面团 = 圆 + 一条弧线；纸袋 = 梯形 + 折口线；闹钟 = 小方块 + 两个小圆铃
- **不出现真实店名、真实食物照片、品牌包装、真人**
- 字体：细软圆润手写体；深色帧保证对比度
- **总时长 ≥ 12 秒**；**导出无声**，配乐用小红书站内音乐

## 四、合成命令（路线 A）

```bash
cd "番外篇-熊也来体验/EP08-早餐店的一天"

ffmpeg -y -framerate 1/2.2 -pattern_type glob -i '0*.png' \
  -vf "scale=1080:1440,fps=30" -c:v libx264 -pix_fmt yuv420p \
  -movflags +faststart 早餐店的一天.mp4
```

**本期推荐加一点缓慢放大**，配合明暗变化更有"一天过去了"的感觉：
```bash
ffmpeg -y -framerate 1/2.2 -pattern_type glob -i '0*.png' \
  -vf "scale=1188:1584,zoompan=z='min(zoom+0.0006,1.06)':d=66:s=1080x1440,fps=30" \
  -c:v libx264 -pix_fmt yuv420p -movflags +faststart 早餐店的一天.mp4
```

> ffmpeg 已装好（`~/.local/bin/ffmpeg`，静态二进制 9.0.1）。

## 五、路线 B 用法

首帧必须喂官方贴图（image-to-video），prompt = [形象锁定正面] + [上表 scene 句] + [动效句]，负面词全带；全文见 [02-通用视频prompt模板.md](../02-通用视频prompt模板.md) B2–B3。

**还原度七项验收（任一不过就弃用该帧）**
- [ ] 眼睛两个纯黑小圆点，无高光/眼白/睫毛
- [ ] 嘴是紧闭小 ω，没张开没牙
- [ ] 无眉毛、无腮红
- [ ] 四肢光滑椭圆，无手指脚趾
- [ ] 白色平涂，无毛发质感
- [ ] 全程一只熊
- [ ] 无 AI 生成文字

> `breakfast`、`food`、`dough` 会引来写实食物质感和真实包装字样。**本期直接走路线 A。**
