# CC Videos

JokeBear 视频创作项目的文案、视频 Prompt、制作记录和 Remotion 源文件。

仓库默认不提交生成的视频、图片、音频、预览输出、依赖目录和 macOS 系统缓存；这些文件保留在本地工作目录中。

## 目录约定

- `小红书/`：按发布日期归档的小红书内容、图文稿、视频稿、Prompt 和对应图片素材。
- `番外篇-熊也来体验/`：番外系列企划、分集文档、分镜和生成脚本。
- `joke_bear/`：熊角色清单与基础素材。
- `jokebear-ref/`：官方贴图、动画帧、参考图和素材分析工具。
- `remotion-jokebear/`：Remotion 视频工程。
- 根目录 Markdown：项目总纲、工具说明和工作记录；根目录脚本用于生成或处理视频。

新内容请放入 `小红书/日期-主题/`，不要在根目录新建日期文件夹。
